# Archived RL experiments

This folder contains earlier trainers, inspectors, plotting scripts, and
refinement tools. They remain available for reference and can be run from the
repository root with `python -m rl.archive.<module>`.

The active Bernoulli trainer and inspector are documented in [`../README.md`](../README.md).
Archived experiments may require their own checkpoints under `rl/artifacts/`.
The learned-tree and sparse-graph experiment notes are also here.
